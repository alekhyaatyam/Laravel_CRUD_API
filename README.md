# Laravel Project App

## Project Build Steps

1. Install PHP dependencies:
   ```bash
   composer install
   ```

2. Install JavaScript dependencies:
   ```bash
   npm install
   ```

3. Compile assets for development:
   ```bash
   npm run dev
   ```

4. Build production assets:
   ```bash
   npm run build
   ```

## Notes

- If you are using Laravel Herd, your application will be available at the Herd local domain for this project.
- If you need to run the application manually, use:
  ```bash
  php artisan serve
  ```
